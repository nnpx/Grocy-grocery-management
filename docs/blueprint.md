# **App Name**: Grocy Dashboard

## Core Features:

- Welcome Section: Display a welcome message to the user with their name.
- Quick Stats Cards: Show total groceries, expiring soon items, and favorite recipes count.
- Expiring Items Display: List expiring items within one week with item name, category, quantity, and expiry date, with expiry date color-coded.
- Recipe Suggestions: Suggest recipes based on user's groceries, displaying the title, type/category, country, favorite button and number of favorites.
- Sidebar Navigation: Provide links to groceries, recipes, my recipes, and favorites pages.
- Mock Data Integration: Utilize mock data to simulate the SQL queries.
- Favorites management: Add / remove recipes to user's favorites

## Style Guidelines:

- Primary color: Fresh green (#4CAF50) for main elements.
- Highlight color: Warm orange (#FFB74D) for interactive elements.
- Favorite color: Playful coral (#FF7043) for favorite indications.
- Background color: Light gray (#F5F5F5) for overall layout.
- Text color: Dark gray (#212121) for readability.
- Headings font: 'Poppins' (sans-serif) in bold for titles and headers. Note: currently only Google Fonts are supported.
- Body font: 'Inter' (sans-serif) in regular for body text and descriptions. Note: currently only Google Fonts are supported.
- Buttons: Uppercase with slight letter spacing.
- Use simple line icons (Lucide/Heroicons) for groceries, recipes, favorites.
- Cards: Rounded corners (2xl), subtle shadows, padding 1.5–2rem.
- Buttons: Rounded, flat color with hover transitions, micro-interactions.
- Lists/Tables: Minimal borders, alternate row shading for readability.
- Smooth hover lift for cards, animated favorite heart, color-coded expiry badges (green/orange/red).
